## Behind the code

My day-to-day stack spans **React interfaces, Node.js services, C++, and databases**. I care about how those pieces fit together: the API a client consumes, the information an interface exposes, and the behavior of the system behind it.

My public projects follow that same curiosity. A webcam becomes an RTSP source. River measurements become tools an AI assistant can query. A small macOS utility makes system health available through MCP.

**I like building the connections that make software useful.**
